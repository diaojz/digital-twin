真人写实形象 · 技术边界说明
本地 Mac 跑不动真人写实形象，这不是软件问题，而是硬件架构决定的。 城北当前使用的是 Live2D 卡通形象，在 Mac 上实时流畅运行，已经是完整产品体验。 真人写实需要上云，下面说清楚为什么、以及怎么做。
本地不可行的原因
  • 真人口型驱动（MuseTalk / SoulX / LiveTalking）依赖 FP8 量化 + FlashAttention-3 + cuDNN fused kernel 加速，这些是 NVIDIA CUDA 的专有特性
  • Apple Silicon（M 系芯片）使用 MPS 后端，不支持 FP8 / FlashAttention-3，计算效率差 10-20 倍，实时根本跑不动
  • 常见误区：「M4 Ultra 128GB 显存不就够了？」—— 装得下 ≠ 算得快，统一内存解决容量问题，解决不了算力问题
  • 调研核实：LiveTalking / MuseTalk / LiteAvatar 在 Mac 均无实时跑通证据（issues 确认）
想要真人形象？租云主机（进阶选学）
推荐框架 LiveTalking（原 metahuman-stream）— GitHub lipku/LiveTalking，支持 WebRTC 推流
云平台 Vast.ai（RTX 4090 约 $0.31/hr）或 RunPod（$0.34-0.69/hr），按需启停约 ¥70/天
接入方式 云端 LiveTalking 跑起来后，把服务地址填到本项目 REALHUMAN_SERVICE_URL，前端自动切换渲染
普通学员用 Live2D 卡通形象已是完整产品
真人形象是进阶方向，按需选学
