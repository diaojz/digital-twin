可接入数字人服务全网调研报告

目标：为 digital-twin 项目寻找可以替换当前 Live2D 形象的数字人服务。重点看公开文档、API/SDK/Web 嵌入、实时对话、试用/价格、接入难度与教学适配度。

调研范围：海外 SaaS / 国内云厂商 / 开源自部署 核心标准：能否接进网页 推荐路线：先 Fay 或 Tavus
一页结论 总览表 重点方案 落地路线

一页结论

如果只是看“数字人效果强不强”，小冰、讯飞、火山、百度、腾讯、华为都很强；但如果看“能不能让我们在一个 Node + HTML 项目里尽快接上”，答案会完全不同。

最终建议：教学项目优先接 Fay Agent，产品展示优先接 Tavus CVI，国产云厂商优先评估 腾讯云智能数智人 与 华为云 MetaStudio。小冰 AI Being、讯飞、火山这类页面更像企业产品/商务咨询入口，不适合作为第一版直接接入对象。
最适合课程教学
Fay

开源、可本地/私有化部署，有文本/语音/数字人驱动接口，适合讲“数字人系统怎么搭起来”。

最适合网页成品展示
Tavus

CVI 明确支持 WebRTC、Embed、React 组件、OpenAPI，更像现成的网页真人视频数字人。

最适合国产云路线
腾讯/华为

公开文档相对完整，但计费、开通、鉴权和工程接入比海外 SaaS/开源方案更重。

重点方案详解

Fay Agent 首推：教学路线

开源可本地部署API/数字人驱动

Fay 是“数字人 & LLM 的全栈 Agent 框架”，支持文字交互、语音交互、自动播报、打断、唤醒、数字人驱动接口，能作为 digital-twin 的下一阶段教学主线。

  • 优点：免费开源、可改、适合课程讲解。
  • 缺点：不是一个“嵌入即用”的 SaaS，需要部署和适配。
  • 适合：本地/私有化数字人 Agent、课程项目升级。

Tavus CVI 首推：产品展示

WebRTCEmbedReact UIOpenAPI

CVI 是实时视频式 AI 数字人接口，包含 Persona、Replica、Conversation。官方文档明确提到 WebRTC、Embed CVI、React 组件库与 OpenAPI。

  • 优点：最像能直接嵌进网页的真人感数字人。
  • 缺点：价格、账号权限、国内访问稳定性要验证。
  • 适合：把 Live2D 换成真人视频式 AI 助手。

小冰 · 讯飞 · 火山

建议落地路线

推荐先做：Fay Agent 分支

因为 digital-twin 是课程项目，最重要的不是“买到最炫的数字人”，而是让零基础学员看懂：前端形象、语音、记忆、LLM、大脑、数字人驱动接口分别负责什么。Fay Agent 最适合承担这条教学线。

  1. 保留当前 Live2D 作为默认形象：AVATAR_PROVIDER=live2d。
  2. 新增 AVATAR_PROVIDER=fay，把 Fay 作为外部数字人 Agent 服务。
  3. 前端新增 Fay 状态卡：未配置时显示部署指引，已配置时连接 Fay API/WebSocket。
  4. 后端新增统一代理：避免浏览器直接暴露 Fay 服务地址或密钥。
  5. 课程里讲“三层架构”：形象层、实时交互层、大脑层。

如果追求展示效果：Tavus

如果你下一步想做一个“看起来像产品发布会”的展示页，Tavus CVI 更适合：它偏真人视频数字人，能通过 WebRTC / Embed / React 组件接入。

验证清单：

  • 是否能拿到免费试用或低成本 starter。
  • 是否能用普通 HTML/iframe 嵌入，而不是必须 React。
  • 是否能接入自定义 LLM 或 webhook。
  • 国内网络下延迟和可用性是否可接受。

供应商咨询时要问的 8 个问题

这部分专门给小冰、讯飞、火山、百度、腾讯、华为等商务型方案使用。只要对方答不清，就不适合作为第一版教学 Demo。
  1. 有没有公开 API / SDK / Web embed 文档？能不能发链接？
  2. 能不能嵌入普通 HTML 页面？是否必须用 React/Vue/小程序/控制台？
  3. 是实时对话，还是只能生成一段数字人视频？
  4. 是否支持把我们自己的 Node 后端 / LLM 接进去？
  5. 前端拿到的是 iframe、WebRTC、视频流、Canvas、SDK，还是别的？
  6. 最低试用成本是多少？有没有免费额度？
  7. 是否支持中文实时打断、唤醒词、低延迟语音对话？
  8. 是否允许课程演示、录屏、公开展示？
