## 0. 结论 / TL;DR

**中文**：经调研，最终方案 = **全阿里 DASHSCOPE 一个 key**：`qwen3-max`(脑) + `CosyVoice`(声) + **`EMO emo-v1`**(脸·对口型)。EMO 比通义万相 wan2.2-s2v **便宜 6 倍**（0.08~0.16 元/秒），且**每月免费 1800 秒**。上传本地图用百炼**免费临时存储**，零 OSS。

**English**: Final stack = **all-Alibaba DASHSCOPE, one key**: `qwen3-max` (brain) + `CosyVoice` (voice) + **`EMO emo-v1`** (face/lip-sync). EMO is **6× cheaper** than Wanxiang wan2.2-s2v (¥0.08–0.16/sec) with **1800 free seconds/month**. Local-image upload uses Bailian's **free temporary storage**, no OSS.

## 1. 数字人 = 三块积木 / 3 building blocks

```
① 脑 LLM (qwen3-max) → ② 声 TTS (CosyVoice) → ③ 脸 数字人 (EMO)
```
> DeepSeek / Kimi 只做①（纯文本），不提供 TTS / 数字人。硅基流动(SiliconFlow) 只做 LLM/TTS/文图视频生成，**无数字人/对口型**（别和硅基智能 DUIX 混淆）。

## 4. 最终选型 / Final stack

| 块 | 选用 | 理由 |
|---|---|---|
| 脑 | qwen3-max | 用户锁定 |
| 声 | cosyvoice-v2 龙婉 | 同 key、150ms、好听便宜 |
| 脸 | **EMO emo-v1** | 同 key、便宜 6 倍、月免费 1800s、真对口型 |
| 形象 | 文生图 wanx2.1-t2i | 同 key、自带公网 URL |
| 上传 | 百炼临时存储 | 免费、48h、零 OSS |

**全程一个 `DASHSCOPE_API_KEY`，零 OSS、零 GPU、零翻墙。**

---

## 5. 关键风险 / Risks

- EMO 是否吃百炼临时存储 `oss://` → 待 M0 实测；不行则轻量图床兜底。
- EMO 偏「唱演」表情或夸张 → 同 endpoint 可切回 wan2.2-s2v。
- 异步生成每轮等十几秒，非实时 → 前端「生成中」过渡；要丝滑实时是后续升级（DVH/Simli）。
- 价格为 2026-06 抓取，落地前以官方控制台为准。
