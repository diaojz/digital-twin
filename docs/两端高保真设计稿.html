设计说明 · 视觉演进点与关键决策
与基准稿的视觉演进
父母端：继承关怀岛屿夜景舞台、状态光环、状态药丸、声波，但字号放大至正文 19–21px，主按钮高度 ≥62px，话题卡替换原有小 chip，去除 topbar 导航（无返回箭头=无二级菜单），整屏信息密度降低约 50%。
子女端：手机壳和屏幕底色加深一档（#c8bce8 起始渐变），营造「工作台」感，区别于父母端的「陪伴型」暖色感。字号和密度与原设置页一致。
三个最关键的组件决策
1. 真人/AI 金色徽章（PRD R3）：真人回信用金色边框卡片（#f0c040）+ 「💌 小军本人回复」徽章，与 AI 回复的紫色毛玻璃卡形成明确视觉层级差异，满足伦理边界 R3 的可区分要求。
2. 父母端话题卡（PRD P-3）：将原有 11.5px 小 chip 放大为独立行卡片（20px 字号，约 46px 高），保证老人视力衰退场景下单次触达率，且点击直触话术库不走 LLM，1s 内开播。
3. 收件箱左边条颜色系统（PRD F4/F5）：红=告警 / 橙=求助待回 / 绿=已回信 / 紫=留言，四色左边条视觉分类，配合右上角徽章文字，让子女在 3 秒内完成收件箱扫描。
